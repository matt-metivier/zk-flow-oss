# zk-flow

Local interactive /workflows for Claude Code SWE lifecycles. Orchestration = .claude/workflows/*.js (generated by build.js from src/).

## Tool routing
Octocode (def/refs) -> CodeGraphContext (callers/blast-radius) -> Repomix (module overview) -> context-mode (big output) -> Read/Grep last.
Run blast-radius (cgc) before editing any symbol.

## Artifacts
Skills/vault/personas live in $ZK_ARTIFACTS_DIR (zk-artifacts). Render selected skills into agent prompts; do not duplicate.

## Memory
beads = structured run memory + self-improve signal (bd CLI). vault = prose. Never put run state in the repo.
